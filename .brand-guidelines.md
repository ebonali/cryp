# CryptoBio.Link Brand Guidelines

## Brand Identity
- **Name**: CryptoBio.Link
- **Domain**: cryptobio.link
- **Tagline**: Your decentralized crypto bio
- **Description**: A platform for creators to connect wallets, showcase links, and receive crypto payments directly with zero fees and complete control.

## Design Language
- **Style**: Professional, minimal, industry-level SaaS aesthetic
- **Inspiration**: Vercel, Next.js, OpenAI styling
- **Primary Color**: Purple/Indigo (250° 85% 60%)
- **Secondary Colors**: Neutral grays and blacks
- **Typography**: Bold, modern, clean
- **Spacing**: Generous whitespace, grid-based layout

## Key Features
- Multi-Wallet Support
- Instant Crypto Settlements
- Zero Platform Fees
- Full Control & Ownership
- Custom Domain Ready
- On-Chain Verification
- Privacy-First Architecture
- Real-time Analytics

## Visual Elements
- Glass morphism effects (subtle)
- Gradient text for emphasis
- Smooth animations
- Dark & Light mode support
- Professional iconography (Lucide)
- Grid backgrounds (subtle)

## Tone of Voice
- Professional yet friendly
- Clear and direct
- Trust-focused
- Creator-centric
- Web3-native perspective

## Database & Auth
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth
- **Storage**: Vercel Blob (for user uploads)
- **Architecture**: Next.js 16 with App Router

## Key Routes
- `/` - Landing page
- `/auth?tab=signup` - Sign up
- `/auth?tab=login` - Login
- `/dashboard` - User dashboard
- `#features` - Feature section anchor

## Typography
- **Font Family**: Inter/Geist (system fonts)
- **Headlines**: Bold, 4xl-7xl sizes
- **Body**: Medium weight, clean sans-serif
- **Contrast**: WCAG AA compliant

## Responsive Design
- Mobile-first approach
- Optimized for all screen sizes
- Touch-friendly CTAs
- Clear navigation on mobile
